# 硬件文档

YuiTag项目提供了多种不同的PCB设计。  
如果你想使用其他的硬件，需要注意修改固件代码中的蜂鸣器引脚以及其他可能影响正常使用的配置(比如NRF52系列的外部晶振配置和DCDC配置)
如你需要对PCB进行修改，请使用**嘉立创EDA专业版**导入**epro2**后缀的工程文件。  

## 设计
目前的PCB设计可匹配市面上售卖的那种小罐装的冻干即溶咖啡，比如瑞幸咖啡元气弹这种，其他品牌的类似包装基本也可兼容。  
这些罐子一般是PP材质，有足够坚固度的情况下也可用美工刀和小电磨轻松加工，在罐子底部合适位置开出蜂鸣器出音孔，在罐子侧面合适位置开出两个挂绳孔，需要注意的是为了确保蜂鸣器发声，可在挂绳孔附近再开一个小孔用来发声。
以及部分品牌的罐子公差可能较大，导致盖子比较松盖不稳，如遇到这种情况也可考虑用不那么强力的双面胶把盖子沾上解决。
(别用太强力的胶，不然到时候换电池拆不下来)  

## PCB制作
每个PCB设计的下单参数均包含在每个PCB文件夹内的README.md中。  
根据其中提供的的板厚，阻抗等参数到嘉立创下单即可。

## PCB焊接
每个PCB设计的焊接注意事项，比如推荐的元件的焊接顺序等页包含在每个PCB文件夹内的README.md中。  
建议按照其中的说明进行操作，否则可能出现焊接顺序错误导致部分元件焊接时操作不便等情况。
