# YuiTag Starlight nRF52832版焊接指南

下单参数：板厚1.2mm

推荐焊接工具：  
建议使用热风枪和电烙铁焊接。  

注意事项：  
PCB天线采用露铜设计，如担心焊接时焊锡不小心弄到天线上，可使用聚醯亚胺高温胶带将天线贴上。  
以及对于烧录固件的调试触电也一样可使用高温胶带贴上避免沾上焊锡。  

推荐焊接顺序：  
优先焊接PCB正面 U1 NRF52832-QFAA 主芯片，  
随后焊接52832外围器件和正面其他阻容器件。  

然后焊接背面的供电滤波及储能电容，
然后焊接CR2032电池座，电池座焊接先在负极焊盘用烙铁镀一层薄锡，随后涂一些助焊膏，  
然后放上电池座，先焊接固定正极，  
然后在电池座负极焊盘再涂一些助焊膏，用烙铁焊接负极即可。

以上焊接方式只使用：热风枪，电烙铁，助焊膏，焊锡丝，  
未用到加热台，焊锡膏以及钢网等。  

**这只是在使用以上装备情况下的推荐方式，如你拥有其他工具，或有不同想法，则可按照你自己习惯的方式焊接，并非必须遵循以上方法。**
